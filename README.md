# ASTRA CRAWL

Self-hosted browser automation and extraction API built on Playwright.

Features:
- rendered HTML/text/link extraction
- screenshots
- persistent browser sessions
- click/fill/type/press/select/check/hover/wait/scroll
- API token authentication
- private-network / cloud-metadata SSRF protection
- bounded concurrency and session TTL

This service is deployed from the `astra-crawl` branch and `/astra-crawl` root directory.
