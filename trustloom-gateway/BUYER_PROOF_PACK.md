# TrustLoom V3 — Buyer Proof Pack

## Implemented asset
TrustLoom is a provider-independent reliability gateway around AI/agent outputs.

### Executable controls
- three policy profiles;
- deterministic verdict engine;
- SHA-256 audit fingerprint;
- HTTP evidence verifier;
- GitHub commit verifier;
- REST API;
- JavaScript SDK;
- health endpoint;
- automated unit + smoke tests;
- GitHub Actions gate.

### Current maturity
**Code asset:** implemented.
**API contract:** implemented.
**External evidence verification:** implemented for HTTP reachability and GitHub commits.
**Durable ledger:** not yet implemented; current ledger is process-local.
**Multi-tenancy/auth/RBAC:** not yet implemented.
**Paid customers / LOIs:** not evidenced.

## 50k thesis
A €50k transaction remains an asking-price thesis, not a proven market valuation. V3 improves the asset by moving from browser demo to integrable gateway with policies, verifiers, SDK, tests and CI.

The next material valuation gates are durable audit storage, authentication, a live deployment, one real workflow integration and external usage evidence.
